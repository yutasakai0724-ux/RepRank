# Changelog

バージョンごとの変更履歴。`pubspec.yaml` の `version` を更新するたびに、このファイルの先頭に追記する運用とする。

> 注意: 2026-06〜08 の開発分は git commit されておらず、履歴の正確な区切りは会話ログベースの概算。
> 今後は各バージョンの区切りで `git add -A && git commit -m "chore: bump to vX.Y.Z+N"` を徹底し、
> 以後は `git log` から機械的に追記できるようにする。

## [1.2.7+14] - 2026-09-27（現在）

### 追加
- **トレーニング時間の記録**（設定でオン。初期オフ）
  - ストップウォッチカードに「トレーニング開始／終了」を追加。RESET で中断（記録しない）
  - 最後の記録から設定時間（初期 1 時間）が過ぎると、最後の記録の時刻で自動終了し通知
  - 開始し忘れの確認（「今後はこのお知らせを表示しない」を選べる）
  - 日別記録一覧で開始・終了時刻を修正、カレンダーのカードに時間を表示
  - DB をスキーマ v4 に更新（開始・終了時刻の列を追加）
- **全ページ共通のフッター**（分析・カレンダー・＋・ルーチン・設定）。＋は今日の記録に追加
- 種目選択シートで**追加した種目の編集・削除**（名前・部位。過去の記録も書き換え）。別端末の種目を記録から補完
- 標準種目を、各部位で知名度の高い順に並べ替え
- 種目別分析: 過去の記録は直近 5 件を表示し、「すべて見る」で月ごとの一覧画面へ
- カレンダー: 選択日の記録を 1 枚のカードに統合。タップで日別記録一覧、長押しで削除。記録のない日に「この日の記録を追加」
- 日別記録一覧に「この日の記録を追加」ボタン
- 前回の記録のペーストを 3 択（キャンセル／メモを含めペースト／記録のみペースト）に変更
- 記録画面: 日付表示、過去日の編集中の注意帯、休憩タイマーの上部固定
- **複数端末の同期**
  - アプリが前面に戻ったときに、他の端末での変更を差分で取り込む
  - 記録の削除を端末間で同期（削除の印。別端末からの再アップロードで復活しない）
  - 設定（体重・ユーザー名・性別・休憩時間・単位・ルーチン・お気に入り・並び順・追加した種目）を端末間で同期

### 修正
- アカウント削除時に、クラウド上のデータ（記録・削除の印・設定）も削除するよう修正
- Widget Extension のバージョンを本体と連動させ、Xcode の警告（CFBundleVersion の不一致）を解消

### 変更
- Firestore ルールを `users/{uid}/` 以下すべて本人のみ読み書き可に変更（**公開前に Console で更新が必要**）
- 過去の記録の編集画面では、その日より前の記録を「前回の記録」にする
- 記録の削除をスワイプから長押し＋確認ダイアログに変更
- 記録画面の「次の種目」ボタンを廃止（フッターの＋で追加）
- 分析タブから部位別カバレッジ・最も近い目標・総合レベルのカードを削除
- 1RM: 回数が 1 以下のときは重量をそのまま使用
- ログイン時の同期を双方向マージ（更新日時が新しい方を採用）に変更
- 推移グラフを自作描画に変更（表示範囲の切替・横スクロール・タップで値表示）
- カレンダータブを高速化（集計と全記録のキャッシュ）
- ロケールを日本語に固定（漢字が中国語の字形で表示される問題の修正）

## [1.2.6+13] - 2026-08-21

### 追加
- セット追加時の重量デフォルトを整数表示に変更（小数点入力は引き続き可能）
- 回数入力欄のキーボード直接入力に対応（±ボタンと併用可能）
- 種目の「全体メモ」「セットメモ」機能を追加（クラウドバックアップ対象）
- 「前回の記録」表示を最高記録1件から**直近セッションの最初の3セット**表示に変更
- 前回の記録をワンタップでペースト（重量・回数・メモを全セット分コピー）
- 休憩タイマー・ストップウォッチの残り時間/経過時間を通知バーに表示
  - Android: `usesChronometer` によるリアルタイム常駐通知
  - iOS: Live Activities（ロック画面・Dynamic Island）実装、Widget Extension 追加

### 修正
- `NSUserTrackingUsageDescription` を削除（ATT審査簡略化のため）
- `pubspec.yaml` のビルド番号を変更しても Xcode 側 `Generated.xcconfig` が更新されず
  App Store Connect アップロードが失敗する問題の原因を特定・ドキュメント化

## [1.2.5+11] - 2026-08-XX

- 体重比・総ボリューム推移グラフがセッション保存時にリアルタイム更新されるよう修正（`SessionManager` を `ChangeNotifier` 化）

- 記録の履歴確認画面から共有ボタン・種目追加ボタン（AppBar右上）を削除
